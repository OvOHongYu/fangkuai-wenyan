# 方块文言 Android App 开发 Spec

## Why
高中生在文言实词、虚词学习中普遍死记硬背义项清单，记得慢、易混淆、不会用。设计稿提出以"一句话画面 + 推导链"为核心的卡片式记忆工具，让义项从本义可视化推导。当前仓库仅有《初步设计稿.md》，无任何工程代码，需从零构建这款 Android 应用。

## What Changes
- 新建 Android 工程：Kotlin + Jetpack Compose + MVVM + Repository + Room + Hilt（按设计稿第六章技术架构）
- 预置 JSON 卡片数据（实词 / 虚词 / 对比卡，Schema 见设计稿第三章），首次启动解析入库
- 四个底部 Tab：首页 / 卡片库 / 检测 / 我的
- 实词卡片详情页：画面 → 本义 → 推导链 → 例句表 → 易错辨析 → 成语验证 → 记忆口诀 → 相关字
- 虚词卡片详情页：画面 → 核心功能 → 判断流程 → 例句表 → 特殊用法（宾语前置）→ 对比辨析 → 口诀
- 搜索、收藏、每日一练、错题本、遗忘曲线复习、学习统计
- 篇目库：覆盖统编版高中语文教材（必修上/下册、选择性必修上/中/下册）文言文与古诗词篇目，每篇含正文、全文翻译、重点字词注释，支持按册别浏览与搜索
- 释义—篇目关联：实词/虚词卡片中每个义项可查看该释义出现过的全部篇目
- 篇目定位阅读窗口：点击篇目名后从底部弹出占 3/4 屏的窗口，自动滚动到该词首次出现位置，同义与异义的出现位置以不同颜色高亮
- 推导链动画、对比卡片、设置（字体大小 / 导出 JSON）
- 双主题皮肤（Minecraft Ore UI 深色 / Microsoft Fluent UI 浅色，设置中可切换）：面板、按钮、Chip、进度条、输入框、底部导航、顶栏全部随皮肤换色；像素字体标题（Monocraft / 方舟像素，正文为系统思源黑体）
- 应用名"方块文言"，图标为等距立方体 + 「文」字
- 按设计稿第七章开发优先级分六阶段交付：脚手架 → 数据库编写 → 核心浏览 → 篇目查找与定位 → 学习闭环 → 体验提升

## Impact
- Affected specs: 无（全新项目，无既有代码）
- Affected code: 新建 app 模块（data / ui / viewmodel / util 分层，见设计稿 6.3）；新增篇目相关数据文件（texts_*.json）与篇目库 UI

## ADDED Requirements

### Requirement: 工程脚手架
系统 SHALL 提供可编译、可安装的 Android 工程，采用设计稿 6.1 技术选型，目录结构符合 6.3 分层。

#### Scenario: 工程构建
- **WHEN** 开发者在 Android Studio 中同步 Gradle 并构建
- **THEN** 工程编译通过，可安装到 Android 8.0（minSdk 24）及以上设备

#### Scenario: 底部导航
- **WHEN** 用户启动 App
- **THEN** 显示底部导航栏，含"首页 / 卡片库 / 检测 / 我的"四个 Tab，可互相切换

### Requirement: 卡片数据层
系统 SHALL 用 JSON 预置卡片数据（设计稿 3.1 / 3.2 / 3.3 Schema），首次启动解析并写入 Room；运行时经 Repository 统一读写。

#### Scenario: 数据导入
- **WHEN** App 首次启动
- **THEN** assets 中的实词 / 虚词 / 对比卡片 JSON 被解析并写入 Room，无崩溃

#### Scenario: 实词 Schema 完整
- **WHEN** 新增一张实词卡片
- **THEN** 包含 id / type / char / pinyin / picture / benyi / chain / examples / idioms / traps / mnemonic / relatedChars 字段

#### Scenario: 篇目 Schema 完整
- **WHEN** 新增一篇篇目
- **THEN** 包含 id / title / author / dynasty / book（教材册别）/ genre / content（正文）/ translation（全文翻译）/ annotations（重点字词注释）/ occurrences（篇目中虚实词出现位置：字 + 对应义项 + 位置）字段

### Requirement: 实词卡片详情页
系统 SHALL 按设计稿 4.2 展示实词卡片：标题（字 + 拼音 + 类型标签）、①一句话画面 ②本义 ③推导链（画面 → 条件 → 义项） ④例句表（义项 / 例句 / 出处 / 译文 / 高考标记） ⑤易错辨析 ⑥成语验证 ⑦记忆口诀 ⑧相关字，并支持上一字 / 下一字切换、收藏、分享入口。

#### Scenario: 查看实词卡片
- **WHEN** 用户从列表或搜索进入实词"爱"
- **THEN** 页面展示画面"一个人紧紧抱住一样东西，舍不得松手"、本义"吝惜、舍不得"及推导链各义项分支

#### Scenario: 例句展示
- **WHEN** 用户查看例句表
- **THEN** 每个义项下列出对应例句、出处、译文，高考真题例句带 🎯 标记

### Requirement: 虚词卡片详情页
系统 SHALL 按设计稿 4.3 展示虚词卡片：画面、核心功能、判断流程（条件 → 关系 / 词性 → 译法 + 例句）、例句表、特殊用法（如宾语前置"何以 = 以何"）、对比辨析入口、记忆口诀，支持上一字 / 下一字。

#### Scenario: 查看虚词卡片
- **WHEN** 用户进入虚词"以"
- **THEN** 展示判断流程（后接名词 / 代词 → 介词；后接动词 / 句子 → 连词）及各分支例句

### Requirement: 首页
系统 SHALL 按设计稿 4.1 提供：搜索框、今日复习卡片（待复习数 + 进度条 + 开始复习）、学习进度（实词 / 虚词）、快捷入口（实词 120 / 虚词 18 / 易混对比）、随机一字。

#### Scenario: 随机一字
- **WHEN** 用户点击随机一字模块的"查看卡片"
- **THEN** 跳转到随机选中的一张卡片详情页

### Requirement: 卡片库与搜索
系统 SHALL 提供卡片库列表：实词（按音序）、虚词（按功能分类）、易混对比卡、我的收藏；搜索框输入汉字直接跳转到对应卡片，无匹配时给出提示。

#### Scenario: 搜索跳转
- **WHEN** 用户在搜索框输入"度"
- **THEN** 直接跳转到"度"的实词卡片详情页

### Requirement: 收藏
系统 SHALL 支持对任意卡片收藏 / 取消收藏，收藏状态本地持久化，卡片库"我的收藏"中可见。

#### Scenario: 收藏持久化
- **WHEN** 用户收藏一张卡片后重启 App
- **THEN** 该卡片仍在"我的收藏"中

### Requirement: 检测（每日一练）
系统 SHALL 提供选择题检测：题目来自卡片的例句 / 推导链，选项为义项或关系，提交后给出对错反馈与解析，展示本次正确率；结果计入学习记录。

#### Scenario: 完成一练
- **WHEN** 用户完成每日一练 5 题
- **THEN** 显示本次正确率，错题自动进入错题本

### Requirement: 错题本
系统 SHALL 自动记录答错的题目（题目、选项、正确答案、解析、来源卡片），支持重练和按卡片筛选。

### Requirement: 遗忘曲线复习
系统 SHALL 按设计稿 5.2 的间隔（10 分钟 / 1 天 / 3 天 / 7 天 / 15 天 / 30 天）为已学卡片生成复习计划；首页"今日复习"展示待复习卡片，可进入复习流程。

#### Scenario: 生成复习计划
- **WHEN** 用户学习完一张卡片
- **THEN** 系统按间隔生成后续 6 次复习提醒，到期卡片进入待复习列表

### Requirement: 学习统计
系统 SHALL 在"我的"页展示打卡天数、已学实词 / 虚词进度、平均正确率、近 7 天学习记录。

### Requirement: 对比卡片
系统 SHALL 按设计稿 4.5 展示对比卡：核心区别、对比表（关系 × 字，✅/❌ + 例句）、例句对比、一句话区分，并可发起对比检测。

### Requirement: 推导链动画
系统 SHALL 支持"动画演示推导过程"：核心画面 → 画面缩小上移 → 连线 → 逐条长出义项 → 弹出例句，约 8 秒，可跳过、可重播。

### Requirement: 设置与导出
系统 SHALL 提供设置：主题皮肤选择（Ore UI 深色 / Fluent UI 浅色）、字体大小调节、卡片导出（JSON，后续可扩展 PDF / 图片）。

#### Scenario: 切换主题皮肤
- **WHEN** 用户在设置中选择"Fluent UI（微软风格 · 浅色）"
- **THEN** 全 App 立即切换为 Fluent UI 浅色皮肤（浅色背景、Fluent 蓝主色、浅色面板），组件（面板 / 按钮 / Chip / 进度条 / 输入框 / 底部导航 / 顶栏）同步换色

#### Scenario: 主题持久化
- **WHEN** 用户切换皮肤后重启 App
- **THEN** 仍保持上次选择的皮肤

### Requirement: 篇目库（高中文言诗词篇目查找）
系统 SHALL 提供高中文言诗词篇目库，覆盖统编版高中语文教材必修上/下册、选择性必修上/中/下册的文言文与古诗词篇目；每篇含标题、作者/朝代、所属册别、正文、全文翻译、重点字词注释；支持按册别分组浏览与按标题/作者搜索。

#### Scenario: 浏览篇目库
- **WHEN** 用户进入篇目库
- **THEN** 篇目按教材册别分组展示（必修上册 / 必修下册 / 选择性必修上册 / 中册 / 下册）

#### Scenario: 搜索篇目
- **WHEN** 用户输入标题或作者关键字
- **THEN** 展示匹配的篇目列表

#### Scenario: 查看篇目详情
- **WHEN** 用户打开一篇篇目（如《赤壁赋》）
- **THEN** 展示正文、全文翻译，并可按重点字词注释查看对应释义

### Requirement: 释义—篇目关联
系统 SHALL 在实词/虚词卡片的例句表中为每个义项提供"出现篇目"入口，点击后列出该字在此义项下出现过的全部篇目。

#### Scenario: 查看释义对应篇目
- **WHEN** 用户在"爱"卡片的"吝惜"义项处点击"出现篇目"
- **THEN** 列出含"爱 = 吝惜"义项的全部篇目（如《齐桓晋文之事》）

### Requirement: 篇目定位阅读窗口
系统 SHALL 在用户从义项的篇目列表点击篇目名后，从屏幕底部弹出占 3/4 屏高度的阅读窗口，加载该篇目并自动滚动到当前字词第一次出现的位置。窗口内 SHALL 只标记"当前卡片的这个字"：与该义项同义的以颜色 A 标记，同一个字表其他义项的以颜色 B 标记；其他字词 SHALL 不被标记。两种标记色 SHALL 高饱和可明显区分，并加粗显示。用户点击任一标记词时，系统 SHALL 弹出说明该处字词与释义的弹窗。窗口内可查看全文翻译与重点字词注释。

#### Scenario: 定位与双色高亮
- **WHEN** 用户从"吝惜"义项点击篇目《齐桓晋文之事》
- **THEN** 底部 3/4 屏窗口打开该篇目并滚动至"爱"首次出现处；文中所有"爱"字高亮：表"吝惜"的用颜色 A，表其他义项的用颜色 B；其他字词不着色

#### Scenario: 点击标记词查看释义
- **WHEN** 用户点击文中任一高亮标记的"爱"字
- **THEN** 弹出弹窗显示该处"爱"的释义、注释，并说明其与当前查看义项是否相同

### Requirement: 篇目普通阅读模式
系统 SHALL 在用户从篇目库正常进入篇目详情时以纯文本展示原文，不做任何字词标记；双色高亮仅在从卡片"出现篇目"进入的定位阅读窗口中出现。

#### Scenario: 正常浏览篇目
- **WHEN** 用户从篇目库打开《劝学》原文
- **THEN** 正文以普通文本展示，无任何字词高亮标记
